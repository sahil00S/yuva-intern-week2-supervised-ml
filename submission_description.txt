This project focuses on implementing and evaluating supervised machine learning algorithms using Python and Scikit-learn. The work contains both classification and regression tasks to demonstrate two major forms of supervised learning. For classification, the Titanic passenger dataset is used to predict the binary target Survived. The dataset is inspected and prepared using appropriate preprocessing techniques, including median imputation for missing numerical values, most-frequent imputation for categorical values, one-hot encoding for categorical features, and StandardScaler for models affected by feature scale. Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors models are then trained on an 80/20 train-test split. Their performance is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix. A separate regression task is implemented using Scikit-learn's built-in Diabetes dataset so that Linear Regression can be applied to a continuous numerical target. Regression performance is evaluated with Mean Absolute Error, Mean Squared Error, and R² score. The project emphasises not only model training but also understanding how different algorithms behave, why preprocessing choices are made, and how evaluation metrics should be interpreted. The final repository contains a Jupyter notebook, standalone Python training script, datasets, result tables, evaluation figures, saved model pipelines, requirements, and a README for reproducibility. This provides a complete workflow from data preparation to model evaluation and documentation.
